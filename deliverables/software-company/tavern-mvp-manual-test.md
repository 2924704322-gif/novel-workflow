## 模块 D：.md 同步（syncDocsToTavern）

> 依赖：项目中已有 `.md` 文档（从书架某本书进入 → 右栏「文档」分段，能看到 world / character 类文档）

| # | 操作步骤 | 预期结果 | 实测 |
|---|---------|---------|------|
| D1 | 在项目文档区确认有至少一个 `kind="world"` 的 `.md` 文档 | 确认存在 | □ |
| D2 | 世界书 Tab → 点击「.md 同步」按钮 | 短暂 loading 后提示「同步完成」 | □ |
| D3 | 同步后查看世界书条目表 | 每个 world 文档对应生成一条 `LorebookEntry`，`content` = 文档 body，`novelchat.sourceDoc` = 文档名。新建条目的 keys 为空数组、enabled=true、insertion_order=按序递增 | □ |
| D4 | 修改世界书中某条目的 keys（如 "测试关键词"）→ 再次点击「.md 同步」 | 该条目的 `content` 更新为最新文档 body，但 keys 仍然为「测试关键词」（人维护字段不被覆盖） | □ |
| D5 | 在项目文档区有至少一个 `kind="character"` 的文档（`人物设定_<name>.md`）→ 同步 | 对应角色卡（codexId 匹配）的 `description` 字段更新为该文档 body | □ |
| D6 | 同步后检查角色卡其他字段（personality / scenario / first_mes） | 保持同步前状态，未被覆盖 | □ |
| D7 | 同步后检查 `data/projects/<id>/` 下的 `.md` 文件 | 内容不变（Q5：不同步回写 `.md`） | □ |
| D8 | 连续点击两次「.md 同步」 | 第二次与第一次结果一致，不产生重复条目（幂等） | □ |
